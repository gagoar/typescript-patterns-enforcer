03

Automatic

Runs after every edit.

The hook reads the file Claude just edited. If a check fails, the message goes to Claude and Claude fixes the file before moving on. Clean files produce no output.

  • TriggerOne PostToolUse hook, in hooks/hooks.json. It runs node engine/dist/check.js.
  • ScopeOnly .ts and .tsx files.
  • OutputViolations go to stderr with exit code 2, which sends them back to Claude.
  • Side effectsNone: the engine's own code writes nothing to disk, makes no network calls, and starts no other process.
  • No NodeIf Node is missing or the check cannot run, the hook exits with no output. The skill's written rules then remain the only enforcement.
04

What you get

Three parts, one standard.

Skill

/typescript-patterns-enforcer:check is active while Claude writes or edits TypeScript. It gives inline guidance on type safety, patterns, and anti-patterns.

Agent

typescript-patterns-enforcer:review handles full PR reviews, large refactors, and JavaScript to TypeScript conversions.

Hook

A bundled checker runs after every .ts or .tsx edit. It brings its own parser, and it ignores your repo's config.

05

The core rules

Eleven rules for the skill to enforce.

The skill also covers data over logic, validation at the boundary, and comment discipline. A hook tag marks a rule the hook also checks mechanically.

  1. No anyhookUse unknown and narrow, or write a precise type.
  2. Explicit return typesAnnotate public functions.
  3. interface vs typeinterface for extendable shapes. type for unions, intersections, and mapped types.
  4. readonly by defaultMutable only when mutation is required.
  5. async/await onlyhookNo .then() chains. Return Promise<T> explicitly.
  6. Typed errorsCustom error classes or discriminated-union results.
  7. Constrained generics<TEntity extends BaseEntity>, not <T>.
  8. Composition over inheritancePlain functions and utility types first.
  9. No magic valueshook: numbersName repeated or meaningful literals in comparisons or branching.
  10. Coerce over compareif (!items.length), not items.length === 0.
  11. Every regex carries an examplehookA comment directly above it: plain words, a quoted match and reject, and a pre-filled regex101 link.

The sixteen mechanical checks

The checks find the pattern. Rewriting it well stays with Claude and the skill, because a linter can ban a switch but cannot rewrite one.

no-nested-ternaryNested ternaries
require-regex-exampleA regex literal with no plain-words comment, example, or tester link above it. Advisory: it checks for a quoted string and an https:// link.
no-narrative-commentComments that narrate history. Advisory: it matches a list of phrases, so it misses some and flags some.
no-zero-comparison.length compared with zero (> 0, === 0, >= 1). Coerce it instead.
