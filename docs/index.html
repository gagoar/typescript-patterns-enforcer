What you get

    
Three parts, one standard.

    

      
Skill
/ts-patterns:check is active while Claude writes or edits TypeScript. It gives inline guidance on type safety, patterns, and anti-patterns.

      
Agent
ts-patterns:review handles full PR reviews, large refactors, and JavaScript to TypeScript conversions.

      
Hook
A bundled checker runs after every .ts or .tsx edit. It brings its own ESLint and parser, and it ignores your repo's config.

    

  


  

    
The core rules

    
Ten rules for the skill to enforce.

    
The skill also covers data over logic, validation at the boundary, and comment discipline.

    

  


  

    
Evidence
